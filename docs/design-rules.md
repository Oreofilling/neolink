# NeoLink Desktop 界面设计规则（v7d）

> 2026-11 v7d 设计轮定稿。本文是 tokens.dart（`packages/neolink_ui/lib/src/tokens.dart`）
> 之外唯一的规则真源：tokens 定义**值**，这里定义**怎么用**。两者冲突时以本文为准并回改 tokens。
> `tool/gen_tokens.py` 已退役 —— tokens 手工维护，重新生成会覆盖本规则的取值。

## 1. 表面层级（三级）

| 层 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| 页面背景 `background` | `#F6F7F9` | `#0B0D12` | 内容区底色 |
| 侧栏 `sidebar` | `#FAFAFB` | `#0D1016` | 导航列，介于背景与卡片之间 |
| 卡片 `card` | `#FFFFFF` | `#12151B` | 可点击模块、重要结果、表单容器 |
| 悬停面 `hoverBg` / 输入悬停 | `#F1F2F4` | `#191D24` | 行悬停、列表悬停 |

- 内容靠底色差浮起，**卡片不加阴影**。
- 阴影只属于浮层：弹窗、popover 用 `NLShadows.overlay`（`NLCard(elevated: true)`）。
- 暗色边框 `#262B34`，悬停加深 `#343B46`；亮色边框为前景 11%/18% alpha。

## 2. 品牌青色（唯一的焦点色）

青色 `#00919B`（暗色 `#14BBC2`）只承担**焦点/选中/进行中**语义：

- 侧栏当前项：3px 左边条 + 浅青底（`accentCyanBg`）
- 扫描雷达与连接进度的当前步（脉冲点/时间线）
- 输入框焦点边框、按钮键盘焦点环（1.5px spread，无 blur）
- 当前步骤、选中设备行（浅青底 + 左青条）
- 文本链接

**主按钮保持深黑**（暗色反白），不用青色。状态色（绿成功/琥珀警告/红错误）
与品牌色严格互斥：状态永远不冒充焦点，焦点永远不携带状态含义。

## 3. 卡片预算（减少「到处都是框」）

完整卡片只给：**可点击模块、重要结果、异常状态、表单容器**。
其余一律降级：

- 普通信息列表 → 分割线行（历史页是范本）
- 大分区之间 → 留白，不画框
- 卡片内**不嵌套卡片**；预览代码块用边框盒，不是卡片
- 错误提示 → 浅红底（`errorBg`）+ 3px 左红条，不用带边框卡片
- 空态保持一个边框盒，其余地方省框

## 4. 文字层级（NLType）

| 级 | 规格 | 用途 |
|---|---|---|
| pageTitle | 22 Bold | 页面标题 |
| pageTitleSub | 12.5 | 页面说明行 |
| cardTitle | 15 Semibold | 卡片/节标题 |
| body | 13 | 正文、表单标签 |
| aux | 11.5 | 辅助提示、元数据 |
| mono | 11 JetBrains Mono | MAC 后缀、序列号、协议字段、时间戳 |

字号/字重/行高由 NLType 固定，颜色是调用方的事（用 `copyWith(color:)`）。

## 5. 侧栏

- 宽 180；品牌区上留白 22px
- 当前项：3px 青左边条 + 浅青底 + 青色图标；非当前项悬停 `hoverBg`
- 底部固定：版本号（mono，与 exe 版本资源同源 `app_metadata.dart`）+ BLE 状态点

## 6. 扫描页

- 通道环境 = 紧凑状态条（`BLE 可用 · AP 受限 · CT-Disc 不可用`），
  「查看详情」按需展开三卡；设备表是第一视觉焦点
- 设备行：入场淡入 + 上移（200ms）、悬停浅灰底、
  QR 定位 = 浅青底 + 3px 左青条（所有行保留透明 3px 左边保持对齐）
- 连接按钮悬停时才升为实心主按钮（静默列 → 指针下一个目标）

## 7. 连接页（诊断时间线）

纵向时间线：已完成绿勾 / 当前步青色脉冲点 / 未开始灰圈；
连接线当前步之前绿色、之后发丝线。右侧每步耗时（mono），
挂起的读会看到计时增长——这本身就是诊断信号。失败态用错误横幅（§3）。

## 8. 配置页（工作台）

- 上下文条全宽置顶；下方左列（表单/模块列表）独立滚动，
  右栏 344px 常驻（设备信息 + 载荷预览），**主操作钉在右栏底部**
- 已填模块行首显示 6px 青点（固定 8px 槽位保持对齐）
- <940px 降级为单列堆叠（共享滚动）
- 已填内容时「取消会话」必须确认：继续编辑（次按钮）/ 放弃并退出（红实心）

## 9. 桌面端状态反馈

- 所有可点元素具备 hover / pressed / focus 三态；
  实心变体悬停 = 前景 8% 叠色、按压 16%；描边变体悬停 = 填充 + 边框加深
- 焦点环统一青色（§2）；Enter/Space 激活焦点按钮
- 动效时长 150–200ms（`NLDurations.fast`），只动 transform/opacity/边框色
- 每页至多一个循环动画（当前步脉冲/雷达），动画是状态信号不是装饰

## 10. 结果页与历史页

- 结果页主按钮 =「配置下一台设备」（产线循环的下一步），
  旁边复制配置结果 / 导出记录，操作后标签换为「已复制 / 已导出」2s
- 结果页显式身份块：设备名 / 序列号 / 型号 / 完成时间（全时间戳 mono）
- 历史页标注「本次运行记录」生命周期（仅本次运行内，关闭应用即清空），
  提供整表导出；空表时导出禁用
